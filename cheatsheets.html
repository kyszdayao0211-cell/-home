ㄴ/은/는/ㄹ 判断法

동사 · 动词动作

过去·完成-(으)ㄴ먹은 밥吃过的饭
现在·进行-는먹는 밥正在吃的饭
未来·意图-(으)ㄹ먹을 밥要吃的饭
回想-던 / -았던먹던 밥之前(一直)在吃的饭

형용사 · 形容词状态

现在·状态-(으)ㄴ예쁜 꽃漂亮的花
未来·推测-(으)ㄹ예쁠 아이会漂亮的孩子
回想-던예쁘던 그때那时候还挺美的
있다/없다系-는맛있는 · 재미있는例外：这类用 -는，不用 -은 ✗
-는
基本铁定是动词（+ 있다/없다系）。形容词一般不接 -는。
-(으)ㄴ
先看词性 → 动词=过去，形容词=现在。这就是你老混的那一格👆
-(으)ㄹ
未来 / 推测 / 意图，动词形容词都能接。
-던
回想过去。-던=未完/反复，-았던=完成/已断。
⚠️ 同一个 -은，词性一换意思全变
작은 가방
형 작다 → 小的包（现在）
앉은 사람
动 앉다 → 坐下了的人（过去）
长得都是 -은，但形容词是"现在状态"，动词是"已完成"。判断前先问一句：这是动作还是状态？
2 秒分动/形小测：能接现在时 -는다/ㄴ다 的是动词（먹다→먹는다✓），只能 -다 的是形容词（예쁘다→예쁜다✗）。或者：能说 -고 있다 的就是动词（앉고 있다✓ / 예쁘고 있다✗）。
主力句型 · 练到反射
别贪多，把这 10 个练到不用想就出口。商务/口语最扛用。
① 软化·铺垫（口语命脉）
-(으)ㄴ/는데(요)
지금 확인 중인데요…
我正在确认…（铺垫/软化/转折）
-(으)ㄹ 것 같다
가능할 것 같아요.
应该可以。（推测/别把话说太死）
-(으)ㄴ/는 편이다
빠른 편이에요.
算是比较快的。（软化陈述）
② 能力·义务·条件
-(으)ㄹ 수 있다/없다
도와드릴 수 있어요.
我能帮您。
-아/어야 하다(되다)
먼저 확인해야 합니다.
需要先确认。
-(으)면 되다/안 되다
이렇게 하면 될까요?
这样做可以吗？
③ 目的
-기 위해(서) / -도록
확인하기 위해 자료를 보냈습니다.
为了确认，我发了资料。
④ 意向·请求（敬语，商务必备）
-(으)ㄹ게요 / -(으)ㄹ까요?
제가 보낼게요. / 시작할까요?
我来发。/ 我们开始吧？
-아/어 주시겠어요?
확인해 주시겠어요?
能请您确认一下吗？（最稳的礼貌请求）
-다고 하다 →
가능하다고 합니다.
说是可以的。（转述→翻到第二页）
拆包三步
①
先揪出转述核心：-다고 / -냐고 / -라고 / -자고，或它缩剩的那一小截。
②
剥掉它，看被引用的原句是什么。
③
看尾巴上挂的是 하다 的哪种变形（해/하는/해서…）。
还原示范：온대→온다 + 고 해→온다고 해（听说会来）。零件你全都认识。
缩略 ⇄ 完整 · 反查表
-대(요)
-다고 해←陈述
온대요. 说（他）会来。

-냬(요)
-(느)냐고 해←疑问
언제 오냬? 问什么时候来。

-래(요)
-(으)라고 해←命令
빨리 오래요. 叫（我/他）快点来。
命令
-재(요)
-자고 해←共动
같이 가재요. 说一起去吧。
共动
-(이)래(요)
-(이)라고 해←名词/이다
학생이래요. 说是学生。

-았/었대
-았/었다고 해←过去陈述
끝났대요. 说（已经）结束了。

-다는
-다고 하는←当定语

-(으)라는
-(으)라고 하는←命令定语

-자는
-자고 하는←共动定语
